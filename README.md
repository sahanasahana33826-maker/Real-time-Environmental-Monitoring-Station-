# Real-time-Environmental-Monitoring-Station-
## Project Overview

The Real-Time Environmental Monitoring Station monitors temperature and light intensity using an Arduino Uno.

## Components Used
- Arduino Uno
- TMP36 Temperature Sensor
- Photoresistor (LDR)
- 16x2 LCD Display
- NPN Transistor
- Relay
- Diode
- DC Fan
- Resistors and connecting wires

## Working
The temperature sensor measures the surrounding temperature, and the photoresistor detects light intensity. The Arduino processes the sensor readings and displays the values on the LCD. The relay controls the fan based on the programmed conditions.

## Applications
- Environmental monitoring
- Temperature monitoring
- Automatic fan control
